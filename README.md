# Prime Engineering website

One-page website for Prime Engineering, Vatva GIDC, Ahmedabad.
Live at: https://primeengineering3112.github.io

## Files
- `index.html` – the whole page (text, layout and styles)
- `images/` – logo, icon, watermark and work photos

## How to update
- Change text: open `index.html` on GitHub, click the pencil icon, edit, then "Commit changes".
- Replace a photo: Add file > Upload files, upload a new photo with the same name into the `images` folder, then commit.
- The live site refreshes within a few minutes of each commit.
